# Dasha RPG — Беклог ідей

> Сюди скидаємо ідеї, які поки не імплементуємо. Підбираємо коли буде слушно.

## Біографії та довідник персонажів

- **Тап по портрету на сцені** → модалка з ім'ям, аватаркою, bio
  - Закривається тапом по фону або хрестиком
  - Для Даши тап показує її власне «що я знаю / куди йду» (можна динамічно міняти по ходу гри)
- **Сторінка «Знайомі»** на головному екрані → перелік усіх вже зустрітих персонажів
  - Критерій «зустрітий»: ID зʼявлявся в `node.characters` будь-якого пройденого вузла
  - Зберігати у `state` як `metCharacters: Set<CharacterId>` (треба додати в `GameState` + serialize у SaveManager)
  - Локізовані іконки lock/unknown для незустрітих
- **Прогресивне розкриття bio**: bio може мати кілька «шарів», які відкриваються по ходу гри
  - напр. шар 1 «Викладачка психології» → шар 2 (після того як Даша попрацює над статтею з нею) «Має звичку правити одне речення тричі»
  - Реалізація: bio як `BioLayer[]` з `unlock?: Condition`, або просто масив рядків + flags

## Інші ідеї

- **Тап по локації** → коротке описання місця (Lecture hall 301: «Тут читала першу пару проф. Коваленко…»)
- **«Журнал» з відвіданими нодами** на головному → можна перейти й перечитати ключові репліки
- **Інвентар думок Даши** — флешбеки/мрії, які додаються по ходу
- **Звукова доріжка по локаціях** — кафе має фоновий шум, лекційна — тишу + кашель
