# Dasha RPG — Беклог ідей

> Сюди скидаємо ідеї, які поки не імплементуємо. Підбираємо коли буде слушно.

## Біографії та довідник персонажів

- ✅ **Сторінка «Знайомі»** — реалізовано: `DirectoryScene` + кнопка на title з лічильником `met/total`. Зберігається в `GameState.metCharacters` (Set), серіалізується в SaveManager. Зустрітий = ID був у `node.characters` будь-якого пройденого вузла. Незустрітих видно як силуети `?`. Список скролиться вертикально (drag + wheel)
- **Тап по портрету на сцені (в RPG)** → модалка з ім'ям, аватаркою, bio. Закривається тапом по фону або хрестиком. Для Даші — її власне «що я знаю / куди йду»
- **Тап по картці в довіднику** → та сама модалка з повним bio (зараз вмонтоване в картку, можна винести коли bio розростуться)
- **Прогресивне розкриття bio**: bio може мати кілька «шарів», які відкриваються по ходу гри
  - напр. шар 1 «Викладачка психології» → шар 2 (після того як Даша попрацює над статтею з нею) «Має звичку правити одне речення тричі»
  - Реалізація: bio як `BioLayer[]` з `unlock?: Condition`, або просто масив рядків + flags

## Інші ідеї

- **Тап по локації** → коротке описання місця (Lecture hall 301: «Тут читала першу пару проф. Коваленко…»)
- **«Журнал» з відвіданими нодами** на головному → можна перейти й перечитати ключові репліки
- **Інвентар думок Даші** — флешбеки/мрії, які додаються по ходу
- ✅ **Звукова доріжка по локаціях** — реалізовано (CC0 ambience + музика лише на title)

## Сюжетні гачки для нових сценаріїв

- **День практики у Спільношколі** — нова локація `spilnoshkola`. Даша приходить, ловить дітей у моменті; куратор дає завдання провести міні-сесію. Вибори: «академічно за CBT», «через гру», «дати дітям самим вести»; контраст між КШЕ-теорією і живою реальністю. Можливо знайомство з куратором як новим персонажем
